# rule-hierarchy-fsm

規則位階式擴充有限狀態機：技術報告〈規則位階式擴充有限狀態機的設計與驗證〉的程式與數據。

本儲存庫收錄報告中所有數字的產生程式與輸出紀錄。所有數字都只在這個載體（自行設計的紙牌遊戲規則系統）上量得，範圍與限制見技術報告第 5 節。

## 環境

- Python 3.10 以上（作者以 Python 3.14 重跑驗證）
- 只使用標準函式庫，不需要安裝任何套件

## 重跑全部數據

所有程式與批次檔都在 `程式碼/` 資料夾內，請先進入該資料夾再執行。

**Windows（繁體中文）**：在 `程式碼/` 裡對 `全部跑一次.bat` 點兩下，或在新開的 CMD 中執行：

```
cd /d 你的資料夾路徑\程式碼
全部跑一次.bat
```

作者電腦上全部跑完約 30 分鐘。每一步的畫面輸出存進 `程式碼/紀錄/` 資料夾，檔名依步驟編號；`stats_v3.py` 另外在 `程式碼/` 產生 `res_*.json`。

`全部跑一次.bat` 以 CP950（Big5）編碼存檔，供繁體中文 Windows 直接執行。其他系統請依下表逐步執行，並先設定 UTF-8：

```
chcp 65001
set PYTHONIOENCODING=utf-8
```

若 Python 指令是 `py` 而不是 `python`，請將批次檔中的 `set PY=python` 改為 `set PY=py`。

## 檔案說明
- `程式碼/`：最終版（v6）的全部程式與批次檔。以下至 `res_*.json` 各項都在這個資料夾內。
- `全部跑一次.bat`：依序執行十個步驟的批次檔。
- `反向抽鬼牌v*.py`：各版本引擎。`vC7_0922v6` 為最終版；其餘為報告中比較用的版本（vC6.1、vC7a、vC7b、修正前、中間版、五局版 vD3）。
- `反向抽鬼牌vC7_0922v6_消融M1`–`M8.py`：消融實驗由 `ablation_v6.py` 產生的變體。
- `_common.py`、`event_capture.py`：共用模組與事件擷取層。
- `history.json`、`snapshots.json`：步驟 8 事件重播產生的事件紀錄與快照。
- `res_*.json`：步驟 2 的彙總結果。
- `紀錄/`（最外層）：作者重跑時各步驟的完整輸出。
- `20260919 缺失前提版本/`：修正前的歷史版本，僅供參考，不用於重現報告數字。報告中的「修正前」比較，以 `程式碼/反向抽鬼牌vC7_0919前_0922v6.py` 為準。
